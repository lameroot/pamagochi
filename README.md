# Памагочи

## Game development quick start

```bash
pnpm install
pnpm game           # standalone mock vertical slice
pnpm game:hatching  # start from egg hatching
pnpm game:room      # start from playable capsule room
pnpm check
```

The mock game is fully local. For architecture, runtime modes, Phaser Editor v5/MCP workflow and asset licence rules, see [docs/game-development.md](docs/game-development.md).
